# ブリッジクローズのお知らせ

2024年12月7日、dYdXコミュニティは2025年6月までにwethDYDXスマートコントラクト（ブリッジ）のサポートを終了することを[決議しました](https://www.mintscan.io/dydx/proposals/189)。 6ヶ月の通知期間の後、dYdXコミュニティは2025年6月13日にwethDYDXスマートコントラクト（「ブリッジ」）のサポートを終了することを[決議しました](https://www.mintscan.io/dydx/proposals/254)。 dYdXチェーン上のwethDYDXスマートコントラクトのサポートが終了した結果、dYdXチェーンのバリデータはブリッジを介して送信されるトランザクションを認識しなくなりました。

その結果、ethDYDX保有者は、ethDYDXトークンをdYdXチェーンのDYDXに変換することができなくなりました。wethDYDXスマートコントラクトに送信され、ロックされたethDYDXトークンは、それぞれのdYdXチェーン上のアドレスに反映されません。

ethDYDXブリッジクローズの詳細については、[こちら](https://docs.dydx.community/dydx-token-migration)をご覧ください。

_dYdX財団は、dYdXチェーンにおけるwethDYDXスマートコントラクトのサポート終了に関して、管理権限を有しておらず、積極的に関与したり、いかなる形で影響を及ぼすこともしていないことにご留意ください。dYdXチェーンにおけるwethDYDXスマートコントラクトのサポート終了は、dYdXチェーンのガバナンスによって決定されたものです。dYdX財団はdYdXチェーンのガバナンスに参加しておらず、dYdXコミュニティがdYdXチェーンのガバナンスを通じて下すいかなる決定についても管理権限がありません。結果として、この通知を受け取ることにより、ethDYDX保有者であり、かついかなる対応も取らないことを選択された場合でも、dYdX財団に対して一切の責任や義務を問わないことに、同意したものとみなされます。_

## dYdX v3のサポート終了

dYdX Trading、Inc.は、2024年10月28日にdYdX v3のサポートを終了しました。

ただし、dYdXチェーン、[http://dydx.trade](https://t.co/v3TXeNvCwf)、およびdYdXチェーンAPIのユーザーは影響を受けません。

これを受け、dYdX Foundationの目的に基づき、dYdX v3の終了がdYdX v3のガバナンスやethDYDXおよびwethDYDXトークン保有者に与える影響に関する[よくある質問](https://www.dydx.foundation/blog/dydx-v3-sunset-governance-token-faqs)をご用意しました。

## dYdXチェーン <a href="#dydx-chain" id="dydx-chain"></a>

dYdXプロトコルは現在、**dYdXチェーン**として実装されており、これは**Cosmos SDK**で構築されたプルーフ・オブ・ステーク型ブロックチェーンネットワークで、コンセンサスには**CometBFT**を使用しています。dYdXチェーンのドキュメントは[こちら](https://docs.dydx.community/dydx-unlimited)で入手できます。
