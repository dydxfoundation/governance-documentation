# Desconexión de dYdX v3

dYdX Trading, Inc. terminó dYdX v3 el 28 de octubre de 2024.

Los usuarios de la cadena dYdX, [http://dydx.trade](https://t.co/v3TXeNvCwf) y la API de la cadena dYdX no se ven afectados.

Como tal, y en línea con el propósito [de](https://www.dydx.foundation/blog/dydx-v3-sunset-governance-token-faqs) la Fundación dYdX, hemos preparado una lista de preguntas frecuentes relacionadas con el impacto de la reducción de dYdX v3 en la gobernanza de dYdX v3 y los titulares de tokens de ethDYDX y wethDYDX.
