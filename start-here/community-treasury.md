# 🤝 Казначейство сообщества

18 ноября 2023 года сообщество dYdX [проголосовало](https://dydx.community/dashboard/proposal/16) за мост остатка ethDYDX, накопленного в казне сообщества, из Ethereum в цепочку dYdX. После присоединения сообщество dYdX может использовать DYDX с голосованием руководства в цепочке dYdX.

Подробнее о кассе вознаграждений сообщества цепочки dYdX можно узнать [здесь](https://app.gitbook.com/s/7eKRye9zrZIr1Pp3Q3Mu/modules-and-parameters/community-treasury).
