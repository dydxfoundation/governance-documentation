# 🤝 Community-Treasury

Am 18. November 2023 [stimmte](https://dydx.community/dashboard/proposal/16) die dYdX-Community dafür, das in der Gemeinschaftskasse angesammelte ethDYDX-Guthaben von Ethereum auf die dYdX-Chain zu überführen. Nach der Überbrückung kann die DYDX von der dYdX-Community mit einer Governance-Abstimmung auf die dYdX-Kette verwendet werden.

Weitere Informationen zur [dYdX-Ketten-Community-Treasury](https://app.gitbook.com/s/7eKRye9zrZIr1Pp3Q3Mu/modules-and-parameters/community-treasury) finden Sie hier.
